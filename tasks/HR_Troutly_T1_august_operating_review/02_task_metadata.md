## Reviewer decision rules, recorded in advance

Rows are the 35-row set's, in rubric order. Every row is read from the Wiki.js pages table and
nothing else: chat prose, a file, and a page under another title do not satisfy any row.

1. **The existence rows (1, 17)** pass when a page carrying the exact title, dashes normalised, is
   published. A draft fails. A second page under the same title has to satisfy too.
2. **The Board approval rows (2, 3, 4, 5)** read the Board approval cell of the row keyed on the
   requisition ID. The cell's leading token decides: Approved passes row 2 on all five,
   Not approved passes rows 3, 4 and 5. Approved with a qualifier does not satisfy Not approved.
3. **The status rows (6, 7)** read the hiring status cell the same way. **The date rows (8, 9)**
   pass when the cell carries the date; another date beside it does not save a wrong one.
4. **The owner row (10)** passes when each owner cell carries the named surname.
5. **The recruiting rows (11 to 14)** read the row keyed on the candidate's name, either order,
   in the table that carries the asked column.
6. **The summary rows (15, 16, 33)** read the page's prose outside its tables. Row 15 passes on
   $612,000.00 within a sentence about the budget or the Board; $868,000.00 alone fails. Row 16
   passes on a statement that none or 0 of the approved roles is filled, or that they are
   unfilled. Row 33 passes on 57 within a sentence about BambooHR or active records.
7. **The count rows (18, 25 to 30)** count every ID-keyed row on the tables that carry an open
   requisition column, and require the summary to state the same figure. A right table with a
   wrong summary fails, and a contractor row on the tables is counted against the figure.
8. **The absence rows (21, 22, 23)** pass when the ID sits on no staffed-role table and the page
   names the person or the ID. Absent and unnamed fails. **Row 24** passes when no CTR-keyed row
   sits on those tables and the page names the four or their numbers.
9. **The manager rows (31, 32)** pass when the manager cell of the row keyed on the employee ID
   carries the named surname or the manager's ID.
10. **The form rows (34, 35)** pass when every Board approval cell opens on one of the two
    values, and when no ISO, spelled or day-first date appears on either page.
11. No row reads page paths, headings, section order, column order or the basis wording.
